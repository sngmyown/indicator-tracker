# 07. 다음 개선 로드맵

## 현재 방향성

이제는 기능 추가 속도전이 아니라 운영 안정화 단계다. 자격증 공부를 우선하고, 웹사이트는 실제 사용 중 불편한 부분을 천천히 개선한다.

## 우선순위 1. 안정판 유지

```text
- 현재 정상 작동 버전 백업
- Release 생성
- 백업 JSON 정기 보관
```

## 우선순위 2. 매뉴얼 유지

```text
- 사용법이 바뀌면 docs/02_user_manual.md 업데이트
- 데이터 소스가 바뀌면 docs/03_data_source_signal_rules.md 업데이트
```

## 우선순위 3. 화면 최적화

나중에 맥북에서 실제로 열어보고 조정한다.

점검 항목:

```text
- 카드 간격
- 현재값 박스 크기
- 캘린더 가독성
- 리포트 입력 폼 길이
- 모바일 탭 전환
```

## 우선순위 4. 목표 비중 vs 현재 비중 비교

다음 기능 추가 후보 중 가장 실전성이 높다.

구현 목표:

```text
- 자산별 목표 비중 입력
- 현재 비중 자동 계산
- 목표 대비 초과/부족 표시
- 리밸런싱 필요 여부 표시
- 현금 비중 가이드와 연결
```

예시:

| 자산 | 현재 비중 | 목표 비중 | 차이 | 판단 |
|---|---:|---:|---:|---|
| BMNR | 42% | 40% | +2%p | 유지 |
| NOW | 25% | 30% | -5%p | 추가 검토 |
| AVAV | 18% | 20% | -2%p | 유지 |
| 현금 | 15% | 10% | +5%p | 일부 투입 가능 |

## 우선순위 5. 히스토리 차트

지표별 현재값만 보는 것이 아니라 변화 흐름을 확인하는 기능이다.

후보:

```text
- 8축 점수 히스토리
- VIX 히스토리
- 실질금리 히스토리
- 실업률/신규 실업수당 히스토리
- Retail Sales - CPI 프록시 히스토리
```

## 보류할 기능

현재는 아래 기능을 무리하게 붙이지 않는다.

```text
- 유튜브 자동 요약
- 외부 API 키가 필요한 서버 기능
- 실시간 주가 스트리밍
- 복잡한 백테스트
```

이유:

```text
정적 GitHub Pages 구조와 맞지 않거나, 유지보수 난이도가 높다.
```
