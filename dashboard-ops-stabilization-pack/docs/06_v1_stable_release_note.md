# v1.0 Eight Axis Market Dashboard Stable

## 버전명

```text
v1.0-eight-axis-dashboard-stable
```

## 목적

8축 시장 분석 프레임을 기반으로 자동 지표 수집, 시장 시나리오 판단, 포트폴리오 점검, 캘린더, 주간 리포트 생성을 통합한 개인 시장 운용 대시보드의 첫 안정판이다.

## 핵심 기능

```text
- 자동 시장 지표 수집
- 8축 시장 스코어링
- 선행/동행/후행 지표 분류
- 골디락스 존 표시
- 현재값 강조 및 신호 색상 표시
- 시나리오 대응 계획
- 수동 입력 패널
- 포트폴리오 자산 배분 파이차트
- 포트폴리오 보유 자산 수정/삭제
- 전체 데이터 백업/복원
- 체크리스트 완료 기록
- 월간 캘린더
- 경제 이벤트 직접 등록
- FactSet + Investing.com 뉴스 3개 + 8축 신호 기반 주간 시장 리포트 생성
```

## 8축 구성

```text
1. 금리/유동성
2. 기업 실적/가이던스
3. 자금 흐름
4. 고용/경기 사이클
5. 소비/수요
6. 기업 마진
7. 달러/원자재
8. VIX/변동성
```

## 운용 원칙

```text
4축 이상 긍정 → 위험자산 우호 / 강세 가능성
4축 이상 부정 → 방어 우선 / 약세 가능성
혼재 → 횡보 또는 변동성 장세
```

## 안정판 기준

이 버전은 기능 추가보다 운영 안정성을 우선한다. 이후 개선은 아래 순서로 진행한다.

```text
1. 사용 매뉴얼 정리
2. 데이터 소스 기준표 보강
3. 맥북/모바일 화면 최적화
4. 목표 비중 vs 현재 비중 비교
5. 히스토리 차트
```
