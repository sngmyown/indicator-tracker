# 04. 주간 운영 루틴

## 목적

매주 같은 순서로 시장을 점검해 판단의 일관성을 유지한다.

## 월요일

확인 항목:

```text
- CME FedWatch 다음 회의 금리 확률
- 이번 주 주요 실적 발표 일정
- 이번 주 고용/소비/물가 지표 일정
- VIX 절대값
- VIX 선물 구조/프록시
- Retail Sales Growth vs Inflation
- 이번 주 캘린더 이벤트 입력
```

웹사이트 작업:

```text
1. 데이터 업데이트 실행
2. 배포 실행
3. 캘린더 이벤트 확인/추가
4. VIX와 금리축 상태 확인
```

## 화요일

확인 항목:

```text
- S&P 500 EPS Beat Rate
- S&P 500 Revenue Beat Rate
- M7 가이던스 변화
- 기업 실적 발표 중 비용 압박/가격 결정력 언급
- 신용카드 연체율
```

웹사이트 작업:

```text
- 수동 입력 패널 업데이트
- 기업 실적/가이던스 축 점검
- 기업 마진 축 점검
```

## 수요일

확인 항목:

```text
- DXY
- WTI
- 구리
- QQQ/SPY/IWM/SQQQ 흐름
- 10년물 금리
- 2년물 대비 스프레드
```

웹사이트 작업:

```text
- 자금 흐름 축 확인
- 달러/원자재 축 확인
- 금리축과 원자재축의 연결성 확인
```

## 목요일

확인 항목:

```text
- 주간 신규 실업수당 청구건수
- 실업률/NFP 발표가 있는 주라면 고용축 재점검
- 실질금리
- 금리 역전 폭
```

웹사이트 작업:

```text
- 고용축 신호 확인
- 금리/유동성 축과 고용축의 충돌 여부 점검
```

## 금요일

확인 항목:

```text
- FactSet Earnings Report
- 이번 주 경제 상태 요약
- 8축 스코어 변화
- 시장 시나리오 유지/전환 여부
```

웹사이트 작업:

```text
1. 데이터 업데이트
2. 수동 입력 보완
3. 8축 스코어 확인
4. 주간 리포트 초안 생성
```

## 토요일

확인 항목:

```text
- 시간당 평균 임금 상승률
- 주간 강세 섹터 ETF
- 돈의 성격
- 8축 최종 스코어링
- 5개 이상 부정 시 현금 확보 검토
- 원칙 준수 여부 점검
```

웹사이트 작업:

```text
1. Investing.com 인기 뉴스 3개 입력
2. 뉴스별 8축 분류
3. 주간 시장 리포트 생성
4. 포트폴리오 현금 비중 점검
5. 백업 다운로드
```

## 일요일

확인 항목:

```text
- 네이버 경제 분석 리포트
- 포트폴리오 업데이트
- 한 주간 정보 연결
- 다음 주 종목 발굴 준비
```

웹사이트 작업:

```text
- 캘린더 다음 주 이벤트 입력
- 포트폴리오 메모 정리
- 다음 주 확인 신호 기록
```

## 주간 판단 원칙

```text
4축 이상 긍정 → 위험자산 우호 / 강세 가능성
4축 이상 부정 → 방어 우선 / 약세 가능성
긍정·부정 혼재 → 횡보 또는 변동성 장세
```

최종 질문은 항상 다음이다.

```text
지금 사도 될까? ❌
내 시나리오가 유효한가? ✅
```
